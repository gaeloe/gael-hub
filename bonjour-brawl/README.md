# Bonjour Brawl

A friendly cartoon fighting game for kids aged 6–10 that teaches French while they play.

- Plain web page: no build step, no dependencies, no image or sound files (everything is drawn and synthesised in code).
- Run locally: `npx http-server -p 4173 .` then open http://localhost:4173
- Deploy: `npx vercel deploy --prod` from this folder.
- Progress is saved only in the browser (localStorage). No ads, no login, no tracking.

Step 1 (this version): 2 fighters, 1 arena (Paris rooftops), 1 theme (colours), 4 challenge types, power meter, super move, stars.
